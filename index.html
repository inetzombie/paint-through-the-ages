Paint Through the Ages

Four eras of Microsoft's paint program, rebuilt from scratch for the browser. Pick a version — each one has the skin, toolbox and quirks of its time, plus undo, open/save PNG, autosave and touch drawing.

1985
Windows 1.0 PaintMonochrome, tiled windows, 24 fill patterns, FatBits, isometric lines and Bézier curves.
Open
1987
Windows 2.x PaintSame monochrome Paint, now in overlapping windows with minimize and maximize arrows.
Open
1992
Windows 3.1 PaintbrushColor arrives: 28-color palette, scissors and pick, color eraser, linesize box, Pick menu effects.
Open
1995
Windows 95 PaintThe classic: 16 tools, option box, fill modes, magnifier, text toolbar, Flip/Rotate and Stretch/Skew.
Open
Every version has
  • Undo (Ctrl+Z) and the era's Edit menu
  • File > New, Open (any image) and Save as PNG
  • Autosave to this browser (localStorage), restored on return
  • Touch & pen drawing — two-finger drag scrolls, long-press a color for the background color
